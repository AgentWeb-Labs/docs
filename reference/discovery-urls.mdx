AgentWeb publishes machine-readable discovery files at standard well-known URLs. AI agents and integrations should read these files rather than hardcoding assumptions about the tool catalog, auth requirements, or payment protocols. When in doubt, start with the live MCP tool manifest.

## Recommended discovery order

Follow this sequence when onboarding a new integration or when your agent first encounters AgentWeb:

1. Read `/llms.txt` and `/llms-full.txt` for a human- and agent-readable summary of what AgentWeb does.
2. Read `/openapi.json` or `/.well-known/openapi.json` for the full OpenAPI 3.1 contract.
3. Read `/.well-known/mcp/tools.json` and the live MCP tool manifest at `https://mcp.agentweb.us/.well-known/mcp/tools.json`.
4. Read `/.well-known/mcp/apps.json` and the [MCP Tools reference](/reference/mcp-tools) for setup, auth, payment authority, and verification surfaces.
5. For commerce workflows, read `/.well-known/agent-commerce.json`.
6. For delegated auth examples, read the [Authentication guide](/guides/connecting-agents).
7. For ACP/UCP bridge support, see [Payments concepts](/concepts/payments).

<Tip>

</Tip>
