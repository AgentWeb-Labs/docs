# AI Agent Payment Processing with AgentWeb

AgentWeb is the execution layer for AI agents that need to route business workflows involving checkout, billing, invoices, subscriptions, receipts, and verification.

## What agents can do

- Audit a business URL for agent commerce readiness.
- Find public pricing, checkout, billing, invoice, and webhook documentation.
- Request a scoped setup session for an Agent Map.
- Create a Dodo hosted checkout after payment authority exists.
- Verify completion through webhook-backed entitlement and verification artifacts.

## What agents cannot do without approval

- Submit forms, start payments, or access private accounts without customer approval.
- Handle raw card data, bank data, credentials, or unrestricted payment-provider keys.
- Treat a checkout redirect as proof of entitlement.

Start with [the AgentWeb company URL audit](https://www.agentweb.us/agent), then read [agent commerce docs](https://www.agentweb.us/docs/agent-commerce) and [the API reference](https://www.agentweb.us/api-reference).
