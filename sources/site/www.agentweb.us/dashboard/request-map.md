# Request a site map.

Queue any website for mapping, and finish builds that need your login.

Submit any domain and the AgentWeb pipeline builds its action map. When a build hits a login or bot wall, it pauses as needs\_login: sign in here and let it finish.

Agents: queue builds with the request\_map MCP tool and poll agentweb\_map\_status. Send the customer to this page only when a build reports needs\_login.
