Agents can evaluate AgentWeb without private access by using public readiness scans, OpenAPI metadata, MCP tool metadata, action-catalog metadata, and payment-authority schema validation.

## Free public checks

- `POST /api/readiness/scan` for public company URL scans.
- `GET /.well-known/mcp/tools.json` for public MCP tool schemas.
- `GET /.well-known/action-catalog.json` for allowed and disallowed action families.
- `GET /.well-known/sandbox.json` for sandbox limits.

## Credentialed setup

Private execution requires an approved Agent Map and scoped AgentWeb key. Paid setup requires a payment authority artifact and Dodo hosted checkout.
