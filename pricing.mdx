Every account starts with a **14-day Starter trial** — included actions, no credit card required.

## Plans

| | Starter | Enterprise |
|---|---|---|
| Price | $500/mo ($350/mo billed annually) | Custom |
| Capacity | 25,000 actions per month | From 5 seats |
| For | Startups putting agents to work | Teams that run at scale |

### Starter

- Full access to the action index
- Any model, one MCP connector
- Agent payments with one-time cards and limits
- Balance and per-session receipts in the dashboard
- Verified receipt on every task
- Priority indexing for new sites
- Priority execution
- Direct founder support

### Enterprise

Everything in Starter, plus:

- Performance SLA
- SOC 2 (audit in progress)
- Custom action maps for private software
- Advanced usage insights
- Dedicated support and migration

Contact [support@agentweb.us](mailto:support@agentweb.us) or [book a demo](https://www.agentweb.us/demo).

## How credits work

Roughly one credit per completed action — one action per execute step. Failed actions are refunded, and `read_page` is free. The exact credit cost is shown before every run, and every task returns a verified completion receipt.
