AgentWeb prices by verified work. One action is one executed step on a website (sending a message, submitting a form, placing an order step), metered in the dashboard as one credit per completed action. Reading pages is free up to 20 reads an hour per account (after that a read counts as an action), your balance is always visible in the dashboard (with per-session receipts on the Usage tab and a warning when you run low), and only work that verifiably completes is billed. Failed tasks are never billed: if AgentWeb fails to complete a task, the retry is on us.

REST API calls meter identically: one completed action through POST /api/execute is one credit, exactly as over MCP, with the same refund on failure.

Creating an account is free, with any email.
