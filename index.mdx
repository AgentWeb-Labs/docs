AgentWeb is a network-level web action layer that connects your AI agent to supported tasks on real websites. Instead of driving a browser, your agent calls named actions with typed inputs and receives structured results plus a verification receipt for every completed task.

## Connect in three steps

<Steps>
  <Step title="Add the MCP server">
    Run one command in Claude Code to register the AgentWeb Streamable HTTP MCP server:

    ```bash
    claude mcp add agentweb --transport http https://mcp.agentweb.us/mcp
    ```

    Using a different MCP client? Add `https://mcp.agentweb.us/mcp` as a remote Streamable HTTP server in your client's settings.
  </Step>
  <Step title="Sign in once via the claim link">
    Your agent will return a `verification_uri_complete` link. Open it to review the Terms and Privacy Policy, sign in, and your agent automatically receives an `aw_` API key and reconnects with it. No password ever enters the conversation.
  </Step>
  <Step title="Run a real web task">
    Ask your agent to complete a supported website task — order, book, submit, or track. It calls the matching Action Map, executes at the network level, and returns structured results with a verification receipt you can inspect.
  </Step>
</Steps>
