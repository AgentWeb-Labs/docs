AgentWeb connects an existing AI agent to supported web actions through MCP and API. Start with discovery, create an account only when execution requires one, and check the returned status or verification before reporting completion.

## Execution sequence

1. Read a page or call discovery for the target domain.
2. Authenticate before listing or executing mapped actions.
3. Connect the target-site account if the selected action requires it.
4. Confirm the inputs and obtain approval for consequential actions.
5. Execute once and use the structured result to report success, failure, or required intervention.
